# Sistfy

Sistema financeiro desenvolvido como projeto interdisciplinar.

## Tecnologias definidas

- **Linguagem:** Delphi
- **Banco de dados:** MongoDB

## Requisitos e funcionalidades

### 1. Dashboard financeiro

- Exibir o saldo total das contas.
- Exibir receitas e despesas do mês.
- Apresentar gráfico de evolução patrimonial.
- Comparar os resultados com o mês anterior.
- Exibir contas a pagar e a receber.
- Apresentar indicador de economia mensal.

### 2. Gestão de transações

- Cadastrar receitas e despesas.
- Criar categorias e subcategorias personalizadas.
- Registrar transferências entre contas.
- Permitir parcelamento de despesas.
- Configurar movimentações recorrentes.
- Filtrar transações por período, valor, categoria e status.

### 3. Planejamento financeiro

- Definir orçamento mensal por categoria.
- Criar metas de economia.
- Emitir alertas quando o orçamento estiver próximo do limite.
- Prever o saldo futuro.
- Controlar dívidas e parcelas pendentes.

### 4. Relatórios e análises

- Apresentar despesas por categoria.
- Mostrar a evolução das receitas e despesas.
- Gerar fluxo de caixa mensal.
- Comparar períodos.
- Exportar relatórios para CSV ou PDF.
- Calcular indicadores financeiros automaticamente.

### 5. Usuários e segurança

- Oferecer cadastro, login e recuperação de senha.
- Manter os dados financeiros isolados por usuário.
- Definir permissões de acesso.
- Manter histórico de alterações importantes.
- Validar os dados no servidor.
- Armazenar senhas com hash seguro.

## Observações

Este documento registra as informações iniciais fornecidas para o projeto. Decisões adicionais e requisitos podem ser acrescentados conforme o planejamento avançar.
